# DroneVision - Аналіз та обробка зображень дронів за допомогою класичних методів комп’ютерної графіки.

## 1. Опис проєкту

**DroneVision** - це спільний навчальний проєкт, розроблений двома учасниками: Олександром Куцілем та Данилом Проскурою.

Мета проєкту - дослідити та реалізувати класичні методи комп'ютерного зору для обробки зображень, отриманих із дронів. Застосунок дає змогу завантажувати зображення, застосовувати різні алгоритми обробки, переглядати проміжні результати, зберігати оброблені зображення та експортувати показники оцінювання.

Проєкт об'єднує графічний інтерфейс, алгоритми цифрової обробки зображень, роботу з файлами та засоби оцінювання результатів. Усі компоненти є частинами єдиної системи, створеної в межах спільної роботи двох авторів.

## 2. Основні можливості

- Завантаження одного зображення або папки із зображеннями.
- Підтримка форматів JPG, JPEG, PNG і BMP.
- Обробка зображень за допомогою чотирьох алгоритмічних конвеєрів.
- Виявлення контурів за допомогою операторів Превітта та Собеля.
- Бінаризація зображень методом Отсу.
- Сегментація кольорів у просторі HSV.
- Використання морфологічних операцій для обробки результатів.
- Перегляд проміжних етапів і кінцевих результатів.
- Налаштування параметрів обробки.
- Збереження оброблених зображень.
- Обчислення метрик MSE, PSNR і SSIM.
- Експорт результатів оцінювання у файл `metrics.csv`.

### 3.1. Графічний інтерфейс

Графічний інтерфейс створено за допомогою Windows Forms. Він дає змогу вибирати вхідні зображення, налаштовувати параметри алгоритмів, запускати обробку та переглядати результати.

Основна форма містить перший і другий алгоритмічні конвеєри. Окрема форма `Participant2Form` використовується для третього та четвертого конвеєрів.

### 3.2. Обробка зображень

Цей компонент відповідає за виконання алгоритмів цифрової обробки зображень. Він охоплює перетворення колірних просторів, виявлення контурів, бінаризацію, сегментацію та морфологічні операції.

### 3.3. Робота з файлами

Компонент забезпечує завантаження зображень, обробку окремих файлів або папок і збереження результатів у вибраному місці.

### 3.4. Оцінювання результатів

Модуль призначений для розрахунку метрик порівняння зображень і збереження результатів у CSV-файл для подальшого аналізу.

## 4. Реалізовані алгоритми

### 4.1. Оператор Превітта

Використовується для визначення змін інтенсивності пікселів і виділення контурів на зображенні.

Етапи обробки:
1. Перетворення зображення у відтінки сірого.
2. Обчислення градієнта за допомогою оператора Превітта.
3. Порогова обробка з пороговим значенням `T = 80`.

### 4.2. Оператор Собеля

Алгоритм визначає контури за допомогою градієнтів зображення. Вирівнювання гістограми виконується перед виявленням контурів.

Етапи обробки:
1. Перетворення зображення у відтінки сірого.
2. Вирівнювання гістограми.
3. Обчислення градієнта оператором Собеля.
4. Порогова обробка з пороговим значенням `T = 80`.
5. Морфологічне замикання: дилатація, після якої виконується ерозія.

### 4.3. Метод Отсу

Метод Отсу автоматично визначає порогове значення для поділу пікселів зображення на класи за інтенсивністю.

Етапи обробки:
1. Перетворення зображення у відтінки сірого.
2. Автоматичне визначення порога методом Отсу.
3. Бінаризація зображення.
4. Морфологічне відкриття: ерозія, після якої виконується дилатація.
5. Використання хрестоподібного структурного елемента розміром 3×3.

### 4.4. Сегментація у просторі HSV

Алгоритм виділяє області зображення за заданими діапазонами кольорів.

Етапи обробки:
1. Перетворення зображення з RGB у HSV.
2. Вибір діапазонів відтінку, насиченості та яскравості.
3. Виділення пікселів, які відповідають заданим діапазонам.
4. Морфологічна ерозія з хрестоподібним структурним елементом розміром 3×3.

Для отримання потрібного результату необхідно налаштувати діапазони HSV відповідно до кольорів об'єктів, які потрібно виділити.

1. Запустіть застосунок.
2. Виберіть зображення або папку із зображеннями.
3. Виберіть необхідний алгоритм обробки.
4. Налаштуйте параметри алгоритму за потреби.
5. Запустіть обробку.
6. Перегляньте проміжні етапи та кінцевий результат.

Підтримуються формати JPG, JPEG, PNG і BMP.

## 9. Результати роботи

За замовчуванням результати зберігаються в папці `Documents/DroneResults`. За потреби можна вибрати іншу папку.

Програма дає змогу зберігати оброблені зображення та експортувати метрики для подальшого аналізу.

Для порівняння зображень використовуються такі показники:

- **MSE (Mean Squared Error)** - середньоквадратична помилка між зображеннями.
- **PSNR (Peak Signal-to-Noise Ratio)** - пікове відношення сигналу до шуму.
- **SSIM (Structural Similarity Index)** - індекс структурної подібності зображень.

Ці метрики описують відмінності між зображеннями, але не є безпосередніми показниками точності виявлення об'єктів. Для оцінювання якості сегментації потрібні еталонні маски та додаткові показники, наприклад IoU, Precision, Recall і F1-score.

## 10. Обмеження

- Результати виявлення контурів залежать від освітлення, контрастності та текстури зображення.
- Порогові алгоритми можуть потребувати налаштування параметрів для різних умов знімання.
- Якість сегментації HSV залежить від правильно вибраних діапазонів кольорів.
- Морфологічні операції можуть змінювати форму та розміри виділених областей.
- Метрики MSE, PSNR і SSIM не замінюють оцінювання точності виявлення об'єктів за еталонними даними.

# DroneVisionP1 — Fast C# WinForms

Відкрийте `DroneVisionP1.sln` у Visual Studio 2022 (.NET 8, Windows Forms) та натисніть F5.

Реалізовано лише частину учасника №1: Gray → Prewitt → Threshold; Gray → Histogram Equalization → Sobel → Threshold → Closing. Операції обробки реалізовано вручну, без готових фільтрів OpenCV.

Оптимізація: LockBits для конвертації зображень, Parallel.For для градієнтів і морфології, відсутність повторного обчислення grayscale для двох пайплайнів, прогрес за файлами.

Рекомендовано спочатку запустити один файл. Збереження всіх проміжних PNG і розрахунок SSIM можуть займати помітний час на великих фотографіях. Метрики відносно оригіналу не вимірюють якість детекції дрона.

Увага: для побудови та тестування WinForms потрібна Windows з .NET SDK; у середовищі генерації компіляція недоступна.
